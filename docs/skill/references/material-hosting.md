# 参考素材：公网托管与预检

## 为什么本地文件不行

`content` 里的 `reference_video` / `reference_audio` **必须是公网可访问的 URL**。本地路径、`file://`、base64 都会被拒：

```
reference_video must be provided as a web url
```

图片可以走 base64（`data:image/png;base64,...`），但有两条约束：

- 请求体总大小 **≤ 64MB**
- 单文件 ≤ 30MB（图片）/ 200MB（视频）

一段 8.4MB 的竖屏视频，base64 后膨胀到约 11MB，加上其他字段轻松逼近上限——所以**视频一律走 URL，不要试 base64**。

这不是 bug，是产品约束。想通这一点能省掉半天试错。

## 方案选择：第一个要验证的假设

| 方案 | 能否用 | 说明 |
|---|---|---|
| **对象存储（推荐）** | ✅ | 火山 TOS / 阿里 OSS / Cloudflare R2 / 任意公共图床。一次配置，长期可用 |
| 内网穿透隧道 | ⚠️ | 能用但很慢，且把本机暴露到公网，关掉就失效 |
| 本地 HTTP + 局域网 IP | ❌ | 服务端在公网，访问不到你的 192.168.x.x |
| base64 | ❌（视频） | 平台要求 URL |

实测同一段 8.39MB 视频：

| 方式 | 耗时 | 速率 |
|---|---|---|
| TOS 直链 | 1.70s | 4.9MB/s |
| 隧道 | 23.2s | 361KB/s |

差 13 倍。**「能不能用」这个假设最贵，永远第一个测**——先花 10 分钟把桶建好，比花两小时调隧道再推翻要划算。

## 火山 TOS 配置步骤

1. 控制台 → 对象存储 TOS → 开通（按量计费，小体量成本几乎可忽略，具体单价以官网为准）
2. 新建桶：地域选**与方舟同区**（`cn-beijing`），访问权限选**公共读**
3. 上传素材，拿到对象地址，形如：

```
https://<桶名>.tos-cn-beijing.volces.com/<对象路径>/cat.mp4
```

4. **配 CORS**（必须，否则浏览器里预览/预检会被拦）：

| 项 | 值 |
|---|---|
| 来源 Origin | `*`（或精确到 `http://127.0.0.1:5199`） |
| 允许方法 | `GET`、`HEAD` |
| 暴露 Headers | `Content-Length`、`Content-Range`、`Accept-Ranges`、`ETag`、`Last-Modified` |

CORS 没配的症状：`Failed to fetch`、控制台报跨域、预览黑屏。**注意这与「本地服务没起」的报错文案一样，要分清**——先看 Network 面板里请求是否真的发出去了。

5. 桶是私有时，用带签名的临时 URL（有效期要覆盖整个生成时长，建议 ≥ 2 小时）。

## 前端怎么处理 URL 与本地文件

两种入法都要支持，但**约束不同**：

| 素材 | 入法 | 上限 |
|---|---|---|
| 首帧 / 尾帧图 | 拖入或选文件，走 base64 | ≤ 30MB |
| 参考图 | 多选，base64 或 URL | ≤ 30 张 |
| 参考视频 | **填 URL**（或选本地文件仅用于预检，实际仍需 URL） | ≤ 10 个，总时长 ≤ 30s，单个 < 200MB |
| 参考音频 | 填 URL | ≤ 10 段，总时长 ≤ 30s，单个 < 15MB |

本地视频被选中时，正确做法是：**给出明确提示「这个文件需要先上传到对象存储」**，而不是默默 base64 然后提交失败。

## 素材预检（ffprobe）

提交前先读一遍视频参数，把不合规的拦住，比等任务失败（还可能已经计费）便宜得多。

官方六项限制：

| 检查项 | 要求 |
|---|---|
| 时长 | 普通任务 2–30s，**编辑任务 4–30s** |
| 帧率 | 24–60 fps |
| 宽高比 | 0.4–2.5 |
| 像素总数 | 40.8 万 – 829.5 万 |
| 宽高边长 | 各 300–6000 px |
| 文件大小 | ≤ 200MB |

实现要点（`src/probe.js`）：

1. `spawn('ffprobe', [...])`，`-of json`，读 `stream=width,height,r_frame_rate,avg_frame_rate,codec_name` 与 `format=duration,size`
2. 帧率可能是 `30000/1001` 这种分数，要解析成小数
3. **本机没有 ffprobe 时返回 `skipped` 并放行**——预检是辅助，不能拦住正常提交。用 `ENOENT` 判断
4. dataURL 要先落到临时文件才能给 ffprobe，用完删掉
5. 30 秒超时，避免卡住整个请求
6. 服务端**拒绝本地路径**（只接受 http(s) 与 dataURL），否则等于对外开放任意文件读取

返回结构带 `checks[]`（每项 key/label/value/ok/expect），前端直接渲染成 `12s · 1080×1920 · 30fps ✓` 徽标；`taskType` 变了要重算——同一段 3 秒素材，普通任务合规、编辑任务不合规。

## 一个容易忽略的约束

Seedance 2.5 / 2.0 **不支持含真人人脸的参考图/视频**（需走平台授权的虚拟人像或已授权素材）。素材预检拦不住这条，只能靠提示词和文档提前告知用户。
