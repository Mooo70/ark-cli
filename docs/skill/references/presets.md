# 预设：白模参考与绿幕编辑

## 先说结论：API 没有「白模」「绿幕」参数

Seedance 2.5 的 `omni_reference_task_type` 只有 `auto / reference / edit / extend` 四个值，`content.role` 只有 `first_frame / last_frame / reference_image / reference_video / reference_audio`。

所谓白模参考、绿幕编辑，本质都是 **普通参考视频 + 特定写法的提示词**，靠模型语义识别。任何声称「传个 `green_screen: true` 就行」的说法都是错的。

所以这里能做的是**预设**：把三样东西固化下来，一键套用。

1. **参数搭配**（任务类型 / 画幅 / 时长 / 原生音频 / 输出格式）
2. **提示词骨架**（可填空的占位符）
3. **素材要求提示**（告诉用户这段素材该怎么准备）

## 三条预设

| key | 名称 | 参数 | 用途 |
|---|---|---|---|
| `clay` | 白模参考 · 3D预演→实拍质感 | `reference` · `adaptive` · `-1` · 关音频 · mov | 白模预演片 → 实拍质感成片 |
| `green-gen` | 绿幕生成 · 出可抠像素材 | `auto` · 关音频 · mov | 纯文生视频，直出可抠像绿幕素材 |
| `green-edit` | 绿幕换实景 · 补全环境 | `edit` · `adaptive` · `-1` · 关音频 · mov | 绿幕素材 → 换成真实场景 |

`mov` 不是随手选的：`output_format: mov` 是 H.264 + **yuv444p**，而 mp4 默认 yuv420 会在绿幕边缘产生色度溢出，抠出来一圈绿边。凡涉及绿幕，必须 mov。

## 提示词骨架怎么写

以白模为例（完整版见 `assets/baseline/src/presets.js`）：

```
【结构参考】参考 @视频1 的相机机位、镜头运动、角色走位与画面构图，逐帧对齐，不改变画面内容。

【重新生成】只提取白模视频中的几何结构、空间关系与运动轨迹，忽略其灰白素模外观、
无贴图表面与低对比度质感。按以下方向重新渲染：
- 主体：<主体造型与材质>
- 环境：<场景>
- 光照：<光源>
- 质感：接近实拍的影视质感，低饱和，脚下有真实投影

【不出现】灰白素模外观、辅助线、坐标轴、相机锥体、网格线；卡通渲染、塑料玩具感；
画面模糊、闪烁、跳变；主体悬浮离地或被画面边缘裁切。
```

四段式结构，四条都是必须的：

1. **【参考什么】** 明确「保留机位/运动/走位」，否则模型会重新设计镜头。
2. **【忽略什么】** 明确「忽略灰白素模外观」，否则它把白模质感一起渲染下来。
3. **【要什么】** 用占位符分项写（主体/环境/光照/质感），别写成一整段。
4. **【不出现】** 负面清单。**显式写「不出现」比写「不要」有效**，且要具体到「辅助线、坐标轴、相机锥体、网格线」这种物件级。

绿幕预设同理，核心是三个词：**纯色均匀**（无渐变/无纹理/无地面/无墙面/无阴影）、**边缘清晰**（no green spill）、**主体不含绿色**。

`green-edit` 的提示词要多一段【边缘质量】：半透明部位（绒毛、发丝）保持自然、无抠像毛边、无轮廓发亮。

## 预设与显式参数的优先级

**显式写的 flag / 表单值永远赢。** 预设只负责填空。

```
用户选 clay，又手动勾了「生成原生音频」  →  音频开
用户选 clay，没动音频                    →  跟随预设，关
```

实现位置：`normalizeVideoOptions()` 最前面先解预设，后面每个字段都写成 `用户值 ?? 预设值 ?? 默认值`。
网页端套用预设后要：**自动展开高级参数区**（否则用户看不见被改了哪几项）+ 在日志里逐条列出改动。

## 别名

CLI 与 API 都认中文，降低记忆成本：`白模` → `clay`、`绿幕` → `green-gen`、`绿幕换景` → `green-edit`，另加 `white` / `blockout` / `greenscreen` / `keying` 等英文简写。

## 用户必须知道的两个坑

1. **白模要在导出前清干净辅助元素**。轨迹线、坐标轴、相机锥体、网格会被当成场景物体渲染进成片，只留几何体本身。建议白模片长 5–10 秒，太长模型抓不住重点。
2. **绿幕必须 mov**。预设已自动切，但用户若手动改成 mp4，绿边会回来。

这两条要写在预设的 hint 里、显示在网页上，别只写在文档里——用户不会去读文档。

## 加第四条预设的检查表

1. `src/presets.js` 加 `key / name / hint / preset{} / text`
2. 加进 `PRESET_ORDER`（决定下拉顺序）
3. `resolvePreset()` 加别名
4. `--selftest` 补一条：默认参数被套用、显式 flag 能覆盖
5. 网页不用改——预设从 `/api/presets` 来
